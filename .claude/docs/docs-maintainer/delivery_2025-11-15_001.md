##### US-006.1: Calcul Automatique de Progression par Niveau (P0, M)
**Chemin:** `.claude/docs/epics/us-006-1.md`

**Objectif:** Calculer progression pour chaque niveau JLPT (X/Y mots maîtrisés)

**Interface clé:**
```typescript
export interface LevelProgress {
  level: JLPTLevel;
  totalWords: number;        // Nombre total de mots du niveau
  masteredWords: number;     // Mots avec score >= 5
  percentage: number;        // (masteredWords / totalWords) * 100
  isComplete: boolean;       // true si tous les mots >= 5
}
```

**Méthodes à implémenter:**
- `getLevelProgress(level: JLPTLevel): Promise<LevelProgress>`
- `getAllLevelsProgress(): Promise<Map<JLPTLevel, LevelProgress>>`

**Tests:** 5 tests unitaires (0%, 50%, 100%, performance < 50ms)

**Effort:** 4-6h

##### US-006.3: Logique de Déblocage Séquentiel (P0, M)
**Chemin:** `.claude/docs/epics/us-006-3.md`

**Objectif:** Débloquer niveaux automatiquement après maîtrise complète

**Algorithme:**
```typescript
function checkAndUnlockNextLevel(): Promise<void> {
  const unlocked = await getUnlockedLevels();
  const lastUnlocked = unlocked[unlocked.length - 1];

  // Vérifier si dernier niveau complété
  const progress = await getLevelProgress(lastUnlocked);
  if (progress.isComplete) {
    const nextLevel = getNextLevel(lastUnlocked);
    if (nextLevel) await unlockLevel(nextLevel);
  }
}
```

**Effort:** 4-6h
