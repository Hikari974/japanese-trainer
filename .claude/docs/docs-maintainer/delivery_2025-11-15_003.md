**Extrait migration automatique:**
```typescript
function migrateStatistics(stats: UserStatistics): UserStatistics {
  const migrated = { ...stats };

  if (!migrated.unlockedLevels) {
    migrated.unlockedLevels = ['Kana']; // Kana débloqué par défaut
  }

  if (!migrated.levelUnlockDates) {
    migrated.levelUnlockDates = {
      'Kana': new Date().toISOString()
    };
  }

  return migrated;
}
```

**Extrait déblocage niveau:**
```typescript
export async function unlockLevel(level: string): Promise<void> {
  const stats = await loadStatistics();

  if (!stats.unlockedLevels.includes(level)) {
    stats.unlockedLevels.push(level);
    stats.levelUnlockDates[level] = new Date().toISOString();
    await saveStatistics(stats);
  }
}
```

## Décisions Techniques

### Migration Automatique
- **Approche:** Migration idempotente intégrée dans loadStatistics()
- **Rationale:** Zéro friction pour utilisateurs existants, aucune action manuelle requise
- **Garantie:** Migration non-destructive, données existantes préservées

### Default Behavior
- **Nouveaux users:** `unlockedLevels: ['Kana']` par défaut
- **Rationale:** Kana est le niveau d'entrée, toujours accessible

### Timestamps
- **Format:** ISO 8601 (new Date().toISOString())
- **Rationale:** Standard international, compatible JSON, humainement lisible

### Immutabilité
- **getUnlockedLevels():** Retourne copie array (spread operator)
- **Rationale:** Évite mutations accidentelles du state

### Persistence
- **saveStatistics():** Appelée automatiquement après unlockLevel()
- **Rationale:** Garantit cohérence données en temps réel
