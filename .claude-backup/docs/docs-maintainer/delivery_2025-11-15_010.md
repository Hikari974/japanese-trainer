## Changes Delivered

### 1. "Unlock All Levels" Debug Button (app/settings.tsx)

**Location:** Data Management section, after Reset Statistics button
**Lines Added:** +42 (lines 235-275)

**Features:**
- **DEV-only visibility**: Guarded by `__DEV__` flag (production builds won't show this button)
- **Bilingual support**:
  - French: "Débloquer Tous les Niveaux"
  - English: "Unlock All Levels"
- **Functionality**: Async loop through all 6 JLPT levels (Kana → N5 → N4 → N3 → N2 → N1)
- **Integration**: Uses existing `unlockLevel()` function from useStatistics hook
- **Feedback**: Console log confirmation when unlock complete

**Code Pattern:**
```typescript
{__DEV__ && (
  <Button
    onPress={handleUnlockAllLevels}
    backgroundColor="$orange10"
  >
    {/* Bilingual label */}
  </Button>
)}
```

**Use Case:**
- Solo developer testing progression states without manual completion
- Enables quick validation of US-006.7 JLPT progression visualization
- No production impact (completely removed from release builds)
