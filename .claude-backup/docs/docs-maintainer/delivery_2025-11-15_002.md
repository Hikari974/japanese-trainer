### Règles Métier Implémentées

**Critère maîtrise mot :**
```typescript
Mot maîtrisé = Σ(points toutes difficultés) >= 5
```

**Règles pioche cumulative :**
- **Kana :** N5 romaji uniquement
- **N5 :** N5 kanji + N4 romaji
- **N4 :** N5 kanji + N4 kanji + N3 romaji
- **N3 :** N5 kanji + N4 kanji + N3 kanji + N2 romaji
- **N2 :** N5 kanji + N4 kanji + N3 kanji + N2 kanji + N1 romaji
- **N1 :** N5 kanji + N4 kanji + N3 kanji + N2 kanji + N1 kanji

**Pattern :** Chaque niveau débloque les kanji de son niveau + romaji du niveau suivant.
