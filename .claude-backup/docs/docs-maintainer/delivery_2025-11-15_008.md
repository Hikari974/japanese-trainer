### 1. NEW: `app/components/ConfettiEffect.tsx` (+121 lines)
**Purpose:** Custom emoji particle animation component using react-native-reanimated

**Key Features:**
- 8 emoji types: 🎉🎊✨🌟⭐💫🎈🎁
- Physics-based animation with randomized parameters:
  - Velocity: horizontal (-200 to 200), vertical (-400 to -200)
  - Angles: random rotation with spin
  - Gravity simulation for natural falling motion
- Configurable particle count (default 30) and duration (default 3000ms)
- react-native-reanimated shared values for 60fps performance
- Auto-cleanup on animation completion

**Technical Decisions:**
- Custom implementation instead of external library (reduces dependencies)
- Emoji particles for universal support (no image assets needed)
- Reanimated for performance (native driver, smooth animations)

**Code Structure:**
```typescript
interface ConfettiEffectProps {

  duration?: number;
}

// Particle type with physics properties
interface Particle {
  emoji: string;
  x: SharedValue<number>;
  y: SharedValue<number>;
  rotate: SharedValue<number>;
  opacity: SharedValue<number>;
}

export function ConfettiEffect({ isVisible, particleCount = 30, duration = 3000 })
```

### 3. NEW: `app/hooks/useLevelUnlockListener.ts` (+66 lines)
**Purpose:** React hook for managing level unlock events and modal state

**Key Features:**
- Subscribes to unlock events from statistics.ts event system
- Auto-shows modal when level unlock detected
- Manages modal visibility state
- Handles navigation with delay for smooth transitions
- Loads user language preference for modal
- Cleanup on unmount (unsubscribe from events)

**API:**
```typescript
interface UnlockModalState {
  visible: boolean;
  level: JLPTLevel | null;
  totalPoints: number;
  totalAttempts: number;
  language: 'fr' | 'en';
}

export function useLevelUnlockListener() {
  const [modalState, setModalState] = useState<UnlockModalState>({ ... });

  const handleModalClose = () => {
    setModalState(prev => ({ ...prev, visible: false }));
  };

  return { modalState, handleModalClose };
}
```

**Event Handling Pattern:**
```typescript
useEffect(() => {
  const unsubscribe = registerUnlockCallback(async (level) => {
    const stats = await getLevelStatsSummary(level);
    const prefs = await loadPreferences();

    setModalState({
      visible: true,
      level,
      totalPoints: stats.totalPoints,
      totalAttempts: stats.totalAttempts,
      language: prefs.language,
    });
  });

  return () => unsubscribe();
}, []);
```

## Technical Decisions

### 1. Custom Confetti vs External Library
**Decision:** Custom implementation with react-native-reanimated

**Rationale:**
- Full control over animation parameters
- No external dependency maintenance risk
- Smaller bundle size (~121 lines vs typical 5-10KB library)
- Emoji particles (universal, no image assets)
- Reanimated already in project (no new dependency)

**Trade-offs:**
- More code to maintain (acceptable for 121 lines)
- No advanced features (not needed for our use case)

### 2. Global Modal in _layout.tsx
**Decision:** Single modal in root layout instead of per-screen modals

**Rationale:**
- Unlocks can happen from any screen
- Prevents duplicate modal logic
- Single source of truth
- Consistent UX

**Trade-offs:**
- Adds ~10 lines to _layout.tsx (acceptable)
- Hook runs globally (minimal performance impact)

### 3. 300ms Navigation Delay
**Decision:** Add delay between modal close and navigation

**Rationale:**
- Smooth modal close animation
- Prevents jarring instant transition
- Better UX (feels more polished)

**Trade-offs:**
- Slight delay before navigation (acceptable, feels intentional)

### 4. Callback Pattern for Modal Close
**Decision:** onContinue callback instead of direct navigation in modal

**Rationale:**
- Separation of concerns (modal doesn't handle navigation)
- Parent controls timing (can close modal first)
- Reusable component (navigation agnostic)

**Trade-offs:**
- Slightly more code (worth it for cleaner architecture)

## Integration Points

### 1. Statistics Service Event System
**Connection:** useLevelUnlockListener subscribes to `registerUnlockCallback()`

**Flow:**
```
Training → recordAttempt() → checkAndUnlockNextLevel()
  → triggerUnlockCallbacks(level)
    → useLevelUnlockListener receives event
      → Shows modal with stats
```

### 2. User Preferences
**Connection:** Modal loads language preference for bilingual display

**Flow:**
```
useLevelUnlockListener → loadPreferences()
  → Gets language ('fr' | 'en')
    → Passes to LevelUnlockModal
      → Displays localized text
```

### 3. Navigation System
**Connection:** Modal navigates to level progress view on continue

**Flow:**
```
User clicks "Continue" → onContinue() → handleModalClose()
  → setModalState({ visible: false })
    → setTimeout 300ms
      → router.push(`/level-progress/${level}`)
```
