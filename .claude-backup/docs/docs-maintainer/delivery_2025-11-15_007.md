## Files Modified

### 5. `app/services/statistics.ts` (+133 lines)
**Changes:**

**New Function: `getWordProgressForLevel(level: JLPTLevel): Promise<WordProgress[]>`**
- Loads all WordStatistic records for the level
- Aggregates stats across 4 difficulties per word
- Calculates derived fields (hasStarted, isMastered)
- Returns complete WordProgress array sorted by wordId

**Algorithm:**
```typescript
1. Load all words for level from wordData JSON
2. Get all WordStatistic records for level (all 4 difficulties)
3. Group by wordId, aggregate:
   - totalPoints = sum of points across difficulties
   - totalAttempts = sum of attempts
   - successCount = sum of successCount
   - perfectCount = sum of perfectCount
   - lastAttemptDate = most recent across difficulties
4. Calculate derived fields:
   - hasStarted = totalAttempts > 0
   - isMastered = totalPoints >= 5
5. Return sorted by wordId
```

**New Function: `getLevelStatsSummary(level: JLPTLevel): Promise<LevelStatsSummary>`**
- Calls getWordProgressForLevel() internally
- Calculates aggregate statistics:
  - total words count
  - mastered count (>=5 points)
  - inProgress count (1-4 points)
  - notStarted count (0 attempts)
  - totalPoints sum
  - totalAttempts sum
  - globalSuccessRate percentage

**Performance:** Efficient single-pass aggregation, optimized for large word counts.

## Technical Decisions

### Aggregation Strategy
**Decision:** Combine stats across all 4 difficulties per word

**Rationale:**
- User cares about overall word mastery, not difficulty breakdown
- Simplified UI (one progress bar per word, not 4)
- Aligns with calculateLevelProgress() logic (total points, no difficulty weighting)

**Trade-off:** Lost difficulty-level granularity (acceptable for MVP, can add detail view later)

---

### Filter/Sort Defaults
**Decision:**
- Default filter: "All"
- Default sort: "Points ↓" (descending)

**Rationale:**
- "All" shows complete picture on first load
- "Points ↓" highlights mastered words first (motivational)
- Users can quickly switch to "In-Progress" filter to focus study

---

### Mastery Threshold
**Decision:** isMastered = totalPoints >= 5

**Rationale:**
- Consistent with calculateLevelProgress() threshold (5 points = mastered)
- Requires 5 perfect attempts (high bar for true mastery)
- Aligns with level unlock criteria (100% mastered = next level unlocked)

---

### Status Icons
**Decision:**
- ✅ Mastered (green): >= 5 points
- 🔄 In-Progress (blue): 1-4 points
- ⚪ Not-Started (gray): 0 attempts

**Rationale:**
- Visual hierarchy: eye drawn to mastered words first
- Color-coded for quick scanning
- Emoji icons universally understood (no i18n required)
