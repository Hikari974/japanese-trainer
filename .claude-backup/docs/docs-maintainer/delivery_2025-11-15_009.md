## Technical Decisions Documented

### 1. Inline Implementation Strategy
**Decision:** Implement progression section inline in stats.tsx (not separate component)

**Rationale:**
- Code size manageable (192 lines)
- Tightly coupled to stats page state
- No reusability requirement
- Simpler maintenance

**Alternatives Considered:**
- Separate ProgressionSection component (rejected: unnecessary abstraction)

### 2. Map Data Structure for levelsProgress
**Decision:** Use `Map<JLPTLevel, LevelProgress>` instead of object or array

**Rationale:**
- Type-safe key access (JLPTLevel union)
- Efficient lookups in card rendering
- Preserves insertion order
- Familiar React pattern

**Performance:** O(1) lookups, efficient for 6 levels

### 3. Promise.all for Parallel Loading
**Decision:** Fetch all 6 level progressions + unlock status in parallel

**Rationale:**
- Minimizes total load time
- Single state update after all data ready
- Prevents multiple re-renders
- Better UX (loading spinner covers all)

**Performance:** ~6x faster than sequential fetching

### 4. useMemo for Expensive Calculations
**Decision:** Memoize globalProgress, currentLevel, statsByLevel, successRate

**Rationale:**
- Prevents recalculation on every render
- Calculations iterate over Map/arrays (O(n) operations)
- Dependencies correctly specified
- Maintains component performance

**Performance:** Prevents unnecessary work, smooth 60fps rendering

### 5. useCallback for Navigation Handler
**Decision:** Wrap handleLevelTap in useCallback

**Rationale:**
- Stable reference for Pressable onPress
- Prevents child re-renders
- Dependencies: unlockedLevels, router

**Performance:** Avoids recreating function on every render

### 6. Emoji Icons vs Lucide Icons
**Decision:** Use emojis (🔒, 🔄, ✅) for state indicators

**Rationale:**
- Zero dependencies (no icon library needed)
- Simple visual indicators
- Matches plan specification initially

**Trade-off:** May render inconsistently across platforms (Code Review suggestion to replace)

**Future Consideration:** Replace with lucide icons for consistency (L1 issue)
