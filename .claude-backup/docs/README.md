# Agent Plans

This folder contains implementation plans created by agents.

Plans are organized by agent type:
- `devops/` - DevOps Expert plans (Docker, CI/CD, deployment)
- `backend/` - Backend Expert plans (framework-specific)
- `frontend/` - Frontend Expert plans (framework-specific)
- `database/` - Database Expert plans (schema, migrations)
- `code-review/` - Code Review reports
- `docs-maintainer/` - Documentation Maintainer deliveries

**Note:** This folder should be emptied when copying the template to a new project.
