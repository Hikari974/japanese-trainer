# US-006.8: Migration État Initial pour Utilisateurs Existants

**Epic:** [Epic-006](./epic-006.md) - Système de Progression et Déblocage Séquentiel
**Priorité:** P1 (High - Critique pour déploiement)
**Effort Estimé:** S (2-3h)
**Statut:** DRAFT

---

## User Story

> **En tant que** système de mise à jour
> **Je veux** initialiser correctement l'état de déblocage pour utilisateurs existants
> **Afin de** préserver leur progression et débloquer les niveaux appropriés selon leurs scores actuels

---

## Problème

### Utilisateurs Existants (avant Epic-006)
- Ont des scores `wordScores` sur plusieurs niveaux (ex: N3 commencé)
- N'ont **pas** de champs `unlockedLevels` / `levelUnlockDates`
- Après update app → système déblocage actif
- **Risque:** Tous niveaux verrouillés sauf Kana (perte progression ressentie)

### Solution Attendue
- **Migration automatique** au premier launch post-update
- **Détection intelligente** des niveaux à débloquer selon scores
- **Préservation complète** de `wordScores` existants
- **Rollback possible** via backup

---

## Règles Métier Migration

### Logique Déblocage Rétroactif
```
Pour chaque niveau dans ordre (Kana → N1):
  SI niveau précédent maîtrisé (tous mots >= 5) OU niveau actuel a des scores
    → Débloquer niveau
  SINON
    → STOP (niveaux suivants restent locked)
```

### Exemples Scénarios

**Scénario 1: Nouvel utilisateur (aucun score)**
- Avant: `wordScores: {}`
- Après: `unlockedLevels: ["kana"]`

**Scénario 2: Utilisateur Kana complet**
- Avant: `wordScores: { "あ": 5, "い": 5, ... }` (tous Kana >= 5)
- Après: `unlockedLevels: ["kana", "n5"]` (Kana complété → N5 débloqué)

**Scénario 3: Utilisateur N3 en cours**
- Avant: `wordScores: { "あ": 8, ... (Kana complet), "です": 6, ... (N5 complet), "ください": 4, ... (N4 partiel), "手紙": 3 (N3 commencé) }`
- Après: `unlockedLevels: ["kana", "n5", "n4", "n3"]`
  - Kana complété → N5 unlock
  - N5 complété → N4 unlock
  - N4 pas complété MAIS N3 a des scores → N3 unlock quand même

**Scénario 4: Utilisateur avec "trous" (edge case)**
- Avant: `wordScores: { "あ": 8 (Kana), "手紙": 3 (N3) }` (Kana partiel, N5/N4 vides, N3 commencé)
- Après: `unlockedLevels: ["kana", "n5", "n4", "n3"]`
  - Car N3 a des scores → débloquer jusqu'à N3 inclus

## Spécifications Détaillées

### Architecture Migration

```typescript
// app/core/training/StatsManager.ts
class StatsManager {
  // Clé flag migration
  private static MIGRATION_FLAG_KEY = '@unlock_migration_completed';
  private static STATS_BACKUP_KEY = '@training_stats_backup';

  /**
   * Exécute migration unlock si pas déjà faite
   * Appelée au launch app (dans _layout.tsx)
   * @returns true si migration exécutée, false si déjà faite
   */
  async runUnlockMigration(): Promise<boolean> {
    // Vérifier si déjà migrée
    const migrationDone = await AsyncStorage.getItem(this.MIGRATION_FLAG_KEY);
    if (migrationDone === 'true') {
      console.log('[Migration] Déjà effectuée, skip');
      return false;
    }

    console.log('[Migration] Début migration unlock...');

    try {
      // 1. Backup stats actuelles
      await this.backupStats();

      // 2. Charger stats
      const stats = await this.getStats();

      // 3. Déterminer niveaux à débloquer
      const levelsToUnlock = this.calculateLevelsToUnlock(stats.wordScores);

      // 4. Mettre à jour stats
      stats.unlockedLevels = levelsToUnlock;
      stats.levelUnlockDates = this.generateUnlockDates(levelsToUnlock, stats.lastTrainingDate);

      // 5. Sauvegarder
      await this.saveStats(stats);

      // 6. Marquer migration comme complétée
      await AsyncStorage.setItem(this.MIGRATION_FLAG_KEY, 'true');

      console.log(`[Migration] Succès - ${levelsToUnlock.length} niveaux débloqués:`, levelsToUnlock);
      return true;

    } catch (error) {
      console.error('[Migration] Erreur:', error);
      // Ne pas bloquer l'app si migration échoue
      return false;
    }
  }

  /**
   * Calcule quels niveaux débloquer selon scores existants
   * @param wordScores - Scores actuels utilisateur
   * @returns Array de JLPTLevel à débloquer
   */
  private calculateLevelsToUnlock(wordScores: { [key: string]: number }): JLPTLevel[] {
    const toUnlock: JLPTLevel[] = ['kana']; // Kana toujours débloqué

    for (let i = 1; i < JLPT_LEVEL_ORDER.length; i++) {
      const currentLevel = JLPT_LEVEL_ORDER[i];
      const previousLevel = JLPT_LEVEL_ORDER[i - 1];

      // Vérifier si niveau précédent maîtrisé
      const prevLevelWords = vocabulary.filter(w => w.jlptLevel === previousLevel);
      const prevLevelMastered = prevLevelWords.every(w =>
        (wordScores[w.hiragana] || 0) >= 5
      );

      // OU vérifier si niveau actuel a des scores (cas "trous")
      const currentLevelWords = vocabulary.filter(w => w.jlptLevel === currentLevel);
      const currentLevelHasScores = currentLevelWords.some(w =>
        (wordScores[w.hiragana] || 0) > 0
      );

      if (prevLevelMastered || currentLevelHasScores) {
        toUnlock.push(currentLevel);
      } else {
        break; // STOP déblocage séquentiel
      }
    }

    return toUnlock;
  }

  /**
   * Génère dates déblocage fictives pour migration
   * @param levels - Niveaux à débloquer
   * @param lastTrainingDate - Date dernier entraînement (fallback)
   * @returns Objet levelUnlockDates
   */
  private generateUnlockDates(
    levels: JLPTLevel[],
    lastTrainingDate: string
  ): TrainingStats['levelUnlockDates'] {
    const dates: TrainingStats['levelUnlockDates'] = {};
    const baseDate = lastTrainingDate || new Date().toISOString();

    levels.forEach(level => {
      dates[level] = baseDate; // Même date pour tous (migration)
    });

    return dates;
  }

  /**
   * Backup stats avant migration
   */
  private async backupStats(): Promise<void> {
    const stats = await AsyncStorage.getItem(STATS_KEY);
    if (stats) {
      await AsyncStorage.setItem(StatsManager.STATS_BACKUP_KEY, stats);
      console.log('[Migration] Backup créé');
    }
  }

  /**
   * Rollback migration (dev only)
   * Restaure backup et supprime flag
   */
  async rollbackMigration(): Promise<void> {
    const backup = await AsyncStorage.getItem(StatsManager.STATS_BACKUP_KEY);
    if (!backup) {
      throw new Error('Aucun backup disponible');
    }

    await AsyncStorage.setItem(STATS_KEY, backup);
    await AsyncStorage.removeItem(StatsManager.MIGRATION_FLAG_KEY);
    console.log('[Migration] Rollback effectué');
  }
}
```

### Intégration Root Layout
```typescript
// app/_layout.tsx
import { useEffect, useState } from 'react';
import StatsManager from '@/core/training/StatsManager';

export default function RootLayout() {
  const [migrationDone, setMigrationDone] = useState(false);

  useEffect(() => {
    runMigration();
  }, []);

  async function runMigration() {
    const manager = StatsManager.getInstance();
    const executed = await manager.runUnlockMigration();

    if (executed) {
      console.log('Migration unlock effectuée avec succès');
    }

    setMigrationDone(true);
  }

  // Optionnel: Afficher splash screen pendant migration
  if (!migrationDone) {
    return <SplashScreen />;
  }

  return (
    <Stack>
      {/* ... routes ... */}
    </Stack>
  );
}
```

## Cas de Test

### Tests Unitaires
```typescript
// __tests__/StatsManager.migration.test.ts
import StatsManager from '../StatsManager';
import AsyncStorage from '@react-native-async-storage/async-storage';
import vocabulary from '../data/vocabulary.json';

describe('StatsManager - Migration Unlock', () => {
  let manager: StatsManager;

  beforeEach(async () => {
    await AsyncStorage.clear();
    manager = StatsManager.getInstance();
  });

  describe('calculateLevelsToUnlock', () => {
    it('retourne [kana] pour utilisateur vide', () => {
      const levels = manager['calculateLevelsToUnlock']({});
      expect(levels).toEqual(['kana']);
    });

    it('débloque N5 si Kana complété', () => {
      const kanaWords = vocabulary.filter(w => w.jlptLevel === 'kana');
      const scores: any = {};
      kanaWords.forEach(w => scores[w.hiragana] = 5);

      const levels = manager['calculateLevelsToUnlock'](scores);
      expect(levels).toEqual(['kana', 'n5']);
    });

    it('débloque jusqu\'à N3 si N3 a des scores', () => {
      const scores: any = {
        'あ': 3, // Kana partiel
        '手紙': 2  // N3 (mot aléatoire N3)
      };

      const levels = manager['calculateLevelsToUnlock'](scores);
      expect(levels).toContain('n3');
      expect(levels).toContain('kana');
      expect(levels).toContain('n5');
      expect(levels).toContain('n4');
    });

    it('débloque séquentiellement Kana → N5 → N4', () => {
      const kanaWords = vocabulary.filter(w => w.jlptLevel === 'kana');
      const n5Words = vocabulary.filter(w => w.jlptLevel === 'n5');

      const scores: any = {};
      kanaWords.forEach(w => scores[w.hiragana] = 5);
      n5Words.forEach(w => scores[w.hiragana] = 5);

      const levels = manager['calculateLevelsToUnlock'](scores);
      expect(levels).toEqual(['kana', 'n5', 'n4']);
    });
  });

  describe('runUnlockMigration', () => {
    it('exécute migration pour utilisateur existant', async () => {
      // Setup: Stats anciennes sans unlock fields
      const oldStats = {
        totalQuestions: 50,
        correctAnswers: 40,
        streakCurrent: 3,
        streakBest: 5,
        wordScores: { 'あ': 5, 'い': 5 },
        lastTrainingDate: '2025-11-10T12:00:00Z',
        trainingDates: ['2025-11-10']
      };

      await AsyncStorage.setItem('@training_stats', JSON.stringify(oldStats));

      // Exécuter migration
      const executed = await manager.runUnlockMigration();

      expect(executed).toBe(true);

      // Vérifier stats mises à jour
      const stats = await manager.getStats();
      expect(stats.unlockedLevels).toBeDefined();
      expect(stats.levelUnlockDates).toBeDefined();
      expect(stats.wordScores).toEqual(oldStats.wordScores); // Préservés
    });

    it('ne réexécute pas migration si déjà faite', async () => {
      // 1ère exécution
      await manager.runUnlockMigration();

      // 2ème exécution
      const executed = await manager.runUnlockMigration();

      expect(executed).toBe(false);
    });

    it('crée backup avant migration', async () => {
      const oldStats = { wordScores: { 'あ': 5 } };
      await AsyncStorage.setItem('@training_stats', JSON.stringify(oldStats));

      await manager.runUnlockMigration();

      const backup = await AsyncStorage.getItem('@training_stats_backup');
      expect(backup).toBeTruthy();
      expect(JSON.parse(backup!)).toMatchObject(oldStats);
    });

    it('ne crash pas si erreur migration', async () => {
      // Simuler erreur AsyncStorage
      jest.spyOn(AsyncStorage, 'setItem').mockRejectedValueOnce(new Error('Storage error'));

      const executed = await manager.runUnlockMigration();

      expect(executed).toBe(false); // Retourne false mais ne crash pas
    });
  });

  describe('rollbackMigration', () => {
    it('restaure stats depuis backup', async () => {
      const oldStats = { wordScores: { 'あ': 5 } };
      await AsyncStorage.setItem('@training_stats', JSON.stringify(oldStats));
      await manager.runUnlockMigration();

      // Modifier stats manuellement
      await AsyncStorage.setItem('@training_stats', JSON.stringify({ wordScores: {} }));

      // Rollback
      await manager.rollbackMigration();

      const stats = await manager.getStats();
      expect(stats.wordScores).toEqual(oldStats.wordScores);
    });

    it('throw error si aucun backup', async () => {
      await expect(manager.rollbackMigration()).rejects.toThrow('Aucun backup disponible');
    });
  });
});
```
