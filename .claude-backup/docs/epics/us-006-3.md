# US-006.3: Logique de Déblocage Séquentiel

**Epic:** [Epic-006](./epic-006.md) - Système de Progression et Déblocage Séquentiel
**Priorité:** P0 (Bloquant)
**Effort Estimé:** M (4-6h)
**Statut:** DRAFT

---

## User Story

> **En tant qu'** utilisateur progressant dans l'apprentissage
> **Je veux** que les niveaux JLPT se débloquent automatiquement dans l'ordre Kana → N5 → N4 → N3 → N2 → N1
> **Afin de** suivre une progression pédagogique structurée

---

## Règles Métier

### Ordre de Déblocage Strict
```
Kana (débloqué par défaut)
  ↓ (maîtrise complète = tous mots >= 5 points)
N5 (débloqué)
  ↓ (maîtrise complète N5)
N4 (débloqué)
  ↓ (maîtrise complète N4)
N3 (débloqué)
  ↓ (maîtrise complète N3)
N2 (débloqué)
  ↓ (maîtrise complète N2)
N1 (débloqué)
```

### Définition "Maîtrise Complète"
Un niveau est **maîtrisé** si et seulement si:
- **Tous** les mots du niveau ont `score >= 5`
- `getLevelProgress(level).isComplete === true`

### Comportement Déblocage
- **Automatique:** Vérifié après chaque `recordAnswer()`
- **Séquentiel:** Impossible de débloquer N4 avant N5 (même si N4 maîtrisé)
- **Persistant:** État conservé entre sessions (AsyncStorage)
- **Immédiat:** Feedback utilisateur instantané lors déblocage

### Fonctionnel
- [ ] **AC1:** Kana débloqué par défaut pour tous nouveaux utilisateurs
- [ ] **AC2:** N5 débloqué automatiquement après maîtrise complète Kana
- [ ] **AC3:** Déblocage suit strictement ordre Kana → N5 → N4 → N3 → N2 → N1
- [ ] **AC4:** Impossible de débloquer niveau N sans avoir débloqué N-1 avant
- [ ] **AC5:** Vérification déblocage déclenchée après chaque `recordAnswer()`

- [ ] **AC10:** Tests couvrant scénarios edge (skip niveau impossible, etc.)

## Spécifications Détaillées

### Architecture
```typescript
// app/core/training/types.ts
export const JLPT_LEVEL_ORDER: JLPTLevel[] = ["kana", "n5", "n4", "n3", "n2", "n1"];

export interface LevelUnlockEvent {
  level: JLPTLevel;
  unlockedAt: string; // ISO 8601
  previousLevel: JLPTLevel;
}
```

### Méthodes StatsManager
```typescript
// app/core/training/StatsManager.ts
class StatsManager {
  // ... méthodes existantes ...

  /**
   * Vérifie si un nouveau niveau peut être débloqué et le débloque si oui
   * Appelée automatiquement après chaque recordAnswer()
   * @returns LevelUnlockEvent si déblocage, null sinon
   */
  async checkAndUnlockNextLevel(): Promise<LevelUnlockEvent | null> {
    const unlockedLevels = await this.getUnlockedLevels();

    // Déterminer prochain niveau à débloquer
    const nextLevel = this.getNextLevelToUnlock(unlockedLevels);
    if (!nextLevel) {
      return null; // Tous niveaux déjà débloqués
    }

    // Vérifier si niveau précédent est maîtrisé
    const previousLevel = this.getPreviousLevel(nextLevel);
    const progress = await this.getLevelProgress(previousLevel);

    if (!progress.isComplete) {
      return null; // Niveau précédent pas encore maîtrisé
    }

    // Débloquer niveau suivant
    const wasUnlocked = await this.unlockLevel(nextLevel);
    if (!wasUnlocked) {
      return null; // Déjà débloqué (race condition)
    }

    // Retourner event pour UI
    return {
      level: nextLevel,
      unlockedAt: new Date().toISOString(),
      previousLevel: previousLevel
    };
  }

  /**
   * Détermine le prochain niveau à débloquer (fonction pure)
   * @param unlockedLevels - Niveaux actuellement débloqués
   * @returns Prochain niveau à débloquer, null si tous débloqués
   */
  private getNextLevelToUnlock(unlockedLevels: JLPTLevel[]): JLPTLevel | null {
    for (const level of JLPT_LEVEL_ORDER) {
      if (!unlockedLevels.includes(level)) {
        return level;
      }
    }
    return null; // Tous débloqués
  }

  /**
   * Retourne le niveau précédent dans l'ordre JLPT
   * @param level - Niveau actuel
   * @returns Niveau précédent, "kana" si niveau = "n5"
   */
  private getPreviousLevel(level: JLPTLevel): JLPTLevel {
    const index = JLPT_LEVEL_ORDER.indexOf(level);
    if (index <= 0) {
      throw new Error(`Pas de niveau précédent pour ${level}`);
    }
    return JLPT_LEVEL_ORDER[index - 1];
  }

  /**
   * Override recordAnswer pour trigger vérification déblocage
   */
  async recordAnswer(
    word: string,
    correct: boolean,
    difficulty: Difficulty = 'medium'
  ): Promise<void> {
    // Logique existante recordAnswer
    await this.recordAnswerOriginal(word, correct, difficulty);

    // NOUVEAU: Vérifier déblocage automatique
    const unlockEvent = await this.checkAndUnlockNextLevel();

    if (unlockEvent) {
      // Émettre event pour UI (si système event existe)
      this.emitLevelUnlocked(unlockEvent);
    }
  }

  /**
   * Émet event déblocage (pour feedback UI)
   * Implémentation simple: callback ou EventEmitter
   */
  private levelUnlockCallbacks: ((event: LevelUnlockEvent) => void)[] = [];

  onLevelUnlocked(callback: (event: LevelUnlockEvent) => void): void {
    this.levelUnlockCallbacks.push(callback);
  }

  private emitLevelUnlocked(event: LevelUnlockEvent): void {
    this.levelUnlockCallbacks.forEach(cb => cb(event));
  }
}
```

## Cas de Test

### Tests Unitaires
```typescript
// __tests__/StatsManager.unlock-logic.test.ts
import StatsManager from '../StatsManager';
import { JLPT_LEVEL_ORDER } from '../types';

describe('StatsManager - Unlock Logic', () => {
  let manager: StatsManager;

  beforeEach(async () => {
    await AsyncStorage.clear();
    manager = StatsManager.getInstance();
  });

  describe('getNextLevelToUnlock', () => {
    it('retourne N5 si seulement Kana débloqué', () => {
      const next = manager['getNextLevelToUnlock'](["kana"]);
      expect(next).toBe("n5");
    });

    it('retourne N4 si Kana+N5 débloqués', () => {
      const next = manager['getNextLevelToUnlock'](["kana", "n5"]);
      expect(next).toBe("n4");
    });

    it('retourne null si tous niveaux débloqués', () => {
      const next = manager['getNextLevelToUnlock'](JLPT_LEVEL_ORDER);
      expect(next).toBeNull();
    });
  });

  describe('getPreviousLevel', () => {
    it('retourne Kana pour N5', () => {
      const prev = manager['getPreviousLevel']("n5");
      expect(prev).toBe("kana");
    });

    it('retourne N5 pour N4', () => {
      const prev = manager['getPreviousLevel']("n4");
      expect(prev).toBe("n5");
    });

    it('throw error pour Kana (pas de précédent)', () => {
      expect(() => manager['getPreviousLevel']("kana")).toThrow();
    });
  });

  describe('checkAndUnlockNextLevel', () => {
    it('ne débloque pas N5 si Kana pas maîtrisé', async () => {
      // Setup: 50% Kana seulement
      const kanaWords = vocabulary.filter(w => w.jlptLevel === 'kana');
      for (let i = 0; i < kanaWords.length / 2; i++) {
        for (let j = 0; j < 5; j++) {
          await manager.recordAnswer(kanaWords[i].hiragana, true);
        }
      }

      const event = await manager.checkAndUnlockNextLevel();

      expect(event).toBeNull();
      const unlocked = await manager.isLevelUnlocked("n5");
      expect(unlocked).toBe(false);
    });

    it('débloque N5 après maîtrise complète Kana', async () => {
      // Setup: 100% Kana
      const kanaWords = vocabulary.filter(w => w.jlptLevel === 'kana');
      for (const word of kanaWords) {
        for (let i = 0; i < 5; i++) {
          await manager.recordAnswer(word.hiragana, true);
        }
      }

      const event = await manager.checkAndUnlockNextLevel();

      expect(event).not.toBeNull();
      expect(event!.level).toBe("n5");
      expect(event!.previousLevel).toBe("kana");

      const unlocked = await manager.isLevelUnlocked("n5");
      expect(unlocked).toBe(true);
    });

    it('ne débloque pas N4 si N5 pas encore débloqué', async () => {
      // Setup: N4 maîtrisé mais N5 pas débloqué (cas edge impossible normalement)
      const n4Words = vocabulary.filter(w => w.jlptLevel === 'n4');
      for (const word of n4Words) {
        for (let i = 0; i < 5; i++) {
          await manager.recordAnswer(word.hiragana, true);
        }
      }

      const event = await manager.checkAndUnlockNextLevel();

      // Devrait tenter débloquer N5 (pas N4)
      expect(event).toBeNull(); // N5 pas débloqué car Kana pas maîtrisé
    });

    it('retourne null si tous niveaux déjà débloqués', async () => {
      // Setup: Tous niveaux débloqués manuellement
      for (const level of JLPT_LEVEL_ORDER) {
        await manager.unlockLevel(level);
      }

      const event = await manager.checkAndUnlockNextLevel();
      expect(event).toBeNull();
    });
  });

  describe('recordAnswer - Déblocage automatique', () => {
    it('trigger checkAndUnlockNextLevel après chaque réponse', async () => {
      const spy = jest.spyOn(manager, 'checkAndUnlockNextLevel');

      await manager.recordAnswer('あ', true);

      expect(spy).toHaveBeenCalledTimes(1);
    });

    it('émet event lors déblocage automatique', async () => {
      const mockCallback = jest.fn();
      manager.onLevelUnlocked(mockCallback);

      // Maîtriser Kana
      const kanaWords = vocabulary.filter(w => w.jlptLevel === 'kana');
      for (const word of kanaWords.slice(0, -1)) {
        for (let i = 0; i < 5; i++) {
          await manager.recordAnswer(word.hiragana, true);
        }
      }

      // Dernière réponse → déblocage N5
      const lastWord = kanaWords[kanaWords.length - 1];
      for (let i = 0; i < 5; i++) {
        await manager.recordAnswer(lastWord.hiragana, true);
      }

      expect(mockCallback).toHaveBeenCalledWith(
        expect.objectContaining({ level: "n5" })
      );
    });
  });

  describe('Déblocage séquentiel complet', () => {
    it('débloque Kana → N5 → N4 dans l\'ordre', async () => {
      // 1. Maîtriser Kana
      const kanaWords = vocabulary.filter(w => w.jlptLevel === 'kana');
      for (const word of kanaWords) {
        for (let i = 0; i < 5; i++) {
          await manager.recordAnswer(word.hiragana, true);
        }
      }

      let unlocked = await manager.getUnlockedLevels();
      expect(unlocked).toContain("n5");

      // 2. Maîtriser N5
      const n5Words = vocabulary.filter(w => w.jlptLevel === 'n5');
      for (const word of n5Words) {
        for (let i = 0; i < 5; i++) {
          await manager.recordAnswer(word.hiragana, true);
        }
      }

      unlocked = await manager.getUnlockedLevels();
      expect(unlocked).toContain("n4");
      expect(unlocked).toEqual(["kana", "n5", "n4"]);
    });
  });
});
```

## Points d'Attention

### Performance
- **Optimisation:** `checkAndUnlockNextLevel` appelée APRÈS CHAQUE réponse
  - Considérer throttle (vérifier seulement tous les 5 réponses ?)
  - Ou cache progression avec invalidation intelligente
- **Benchmark:** Mesurer impact sur recordAnswer (ne pas dégrader UX)

### Edge Cases
- **Race Conditions:** Deux réponses simultanées (très rare sur mobile)
- **Migration:** Utilisateurs avec scores N3 existants (géré dans US-006.8)
- **Tous Débloqués:** checkAndUnlockNextLevel retourne null proprement

### UX
- **Feedback Immédiat:** Event `onLevelUnlocked` doit trigger UI feedback (US-006.6)
- **Pas de Frustration:** Progression claire visible (US-006.5)
