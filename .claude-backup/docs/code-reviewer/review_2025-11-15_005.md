#### M2: Map Iteration Could Use Array.from for Clarity

**File:** `app/stats.tsx:64-76`

**Issue:** While `levelsProgress.forEach()` works, converting Map to array entries might be more idiomatic for aggregation calculations.

**Current Code:**
```typescript
const globalProgress = useMemo(() => {
  let totalWords = 0;
  let totalMastered = 0;

  levelsProgress.forEach(progress => {
    totalWords += progress.totalWords;
    totalMastered += progress.masteredWords;
  });

  const percentage = totalWords > 0 ? Math.round((totalMastered / totalWords) * 100) : 0;
  return { totalWords, totalMastered, percentage };
}, [levelsProgress]);
```

**Impact:** Low - Code works correctly, minor style preference

**Alternative (Optional):**
```typescript
const globalProgress = useMemo(() => {
  const totals = Array.from(levelsProgress.values()).reduce(
    (acc, progress) => ({
      totalWords: acc.totalWords + progress.totalWords,
      totalMastered: acc.totalMastered + progress.masteredWords,
    }),
    { totalWords: 0, totalMastered: 0 }
  );

  const percentage = totals.totalWords > 0
    ? Math.round((totals.totalMastered / totals.totalWords) * 100)
    : 0;

  return { ...totals, percentage };
}, [levelsProgress]);
```

**Recommendation:** Optional refactor. Current code is perfectly readable and efficient. Consider if team prefers functional style.

**Severity:** Medium (code quality preference, not required)
