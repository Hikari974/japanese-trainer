### RomajiKeyboard.tsx - MEDIUM Risk

**Factors Mitigating Risk:**
- Pure UI component with clear responsibility
- Memoization patterns reduce risk of performance regressions
- Simple state machine (single state: currentMode)
- No async operations or timers
- No business logic or data transformations
- Easily testable with React Testing Library patterns

**Factors Increasing Risk:**

- Mode switching affects multiple rows/columns
